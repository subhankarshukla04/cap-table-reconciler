Clean cap tables, before the math runs.

Cap-table cleanup is the largest hour drain on a private-company valuations team and a top reason audit memos get sent back. This tool ingests a messy client file, runs a missing-fields checklist, and produces a clean structured liquidation waterfall with breakpoints — the input layer to your existing OPM, Backsolve, or DCF.

Scope.  No 409A. No Backsolve solver. No fair-value computation. No LLM in the calculation pipeline. Every finding is deterministic and rule-based.

Bring a cap table

3 Companion utilities

Three small tools on the same pipeline

  • Live formula workbook — exported from the waterfall page. Edit share counts, prices, LP multiples, or pool sizes in Excel and watch breakpoints, allocations, and the chart update natively. No Python runtime required after export.
  • Side-letter PDF intake — on any review page, drop in a side-letter PDF; pdfplumber extracts text and attaches it as a SideLetter. Text PDFs only.
  • Cap-table snapshot diff — Diff page: upload two .xlsx snapshots, get a structured class-by-class delta with fuzzy-matched class names for the audit memo’s subsequent-events section.
