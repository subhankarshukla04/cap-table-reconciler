What this tool does

Cap-table cleanup is the largest hour drain on a private-company valuations team and one of the top reasons audit memos get sent back. This tool ingests a messy client cap-table file, runs a missing-fields checklist, and produces a clean structured liquidation waterfall with breakpoints. The output is the input layer to your existing OPM, Backsolve, or DCF workflow. The tool itself makes zero valuation judgments.

Scope discipline. This tool stops at clean structured output. No 409A, no Backsolve, no fair-value computation, no LLM in the calculation pipeline. Findings are deterministic and rule-based.

Upload a cap table

Accepts a single .xlsx file with a tab named "Cap Table" (or "Capitalization", "Shareholders", etc.). Optional tabs: "Company", "Convertibles", "Side Letters". Up to 8 MB.

Other tools

Three companion utilities that plug into the same pipeline.

  • Live formula workbook — exported from the waterfall page. Edit share counts, prices, LP multiples, or pool sizes in Excel and watch breakpoints, allocations, and the chart update natively. No Python runtime required after export.
  • Side-letter PDF intake — on any review page, drop in a side-letter PDF; pdfplumber extracts text and attaches it as a SideLetter. Text PDFs only.
  • Cap-table snapshot diff — Diff page: upload two .xlsx snapshots, get a structured class-by-class delta with fuzzy-matched class names (Levenshtein) for the audit memo's subsequent-events section.
